⚙️ How to Run the Programs
Prerequisites
Install a C++ compiler, such as GCC, and ensure that g++ is available in your terminal.

1. Clone the Repository
git clone <YOUR_DSA_CODES_REPOSITORY_URL>
Replace the placeholder with the actual URL of your DSA Codes repository.

2. Navigate to the Directory
cd "DSA Codes"
Use the actual directory name created when cloning the repository.

3. Compile a Program
For example, to compile Binary Search:

g++ binarysearch.cpp -o binarysearch
4. Execute the Program
Windows:

binarysearch.exe
Linux/macOS:

./binarysearch
Repeat these steps for any other .cpp file.

Note: Each program should be compiled and executed separately because the source files have their own main() functions.

⏱️ Time Complexity Reference
Algorithm / Operation	Typical Time Complexity
Binary Search	O(log n)
Bubble Sort	O(n²)
Linked List Traversal	O(n)
Stack Push	O(1)
Stack Pop	O(1)
Queue Enqueue	O(1)
Queue Dequeue	O(1)
Hash Table Insertion	O(1) average
BST Insertion	O(log n) average
Tree Traversal	O(n)
These are general complexities. Actual performance depends on the implementation and input.
